Step 1: Zip your package

The script requires a zip file of your work.
Bash

cd ~/catkin_ws/src
zip -r second_coursework.zip second_coursework

Step 2: Run the Builder (Terminal 1)

This starts the simulation. Run this command and wait for the robot to spin and stop (approx. 15 seconds).
Bash

cd ~/catkin_ws/src/Supplementary_files_20251205/
bash student_aa_run_tester.sh ~/catkin_ws/src/second_coursework.zip /home/k23163890/catkin_ws/src/Supplementary_files_20251205/cs_cw_2526_videos /home/k23163890/catkin_ws/src/second_coursework/cfg/coco.data
